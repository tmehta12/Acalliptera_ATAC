# Acalliptera_ATAC
Code for ATAC-seq analysis of Astatotilapia calliptera embryos (3, 7, 12 dpf), accompanying a paper on chromatin accessibility in a generalist cichlid. Scripts run from raw reads to peaks, genomic annotation, differential accessibility (csaw/edgeR), TF footprinting (HINT-ATAC), regulatory networks and figures.
